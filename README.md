# BacGWAS-Visualizer 🧬📊

**Bacterial GWAS Visualizer & Magnitude Analyzer** 
`BacGWAS-Visualizer` uses a highly optimized, dual-engine modular architecture tailored for microbial population genomics:

1. **The Statistical & Mapping Engine (Python 3):** Handles memory-efficient, line-by-line parsing of large compressed variant files (`.vcf.gz`), executes high-speed spatial coordinate mapping on reference genomes via bidirectional string matching, and performs positional spatial clustering to merge overlapping variants into defined **Regions of Interest (ROIs)**.
2. **The Rendering Graphic Engine (R):** Leverages the unmatched aesthetic and vector-graphics power of `ggplot2`, `patchwork`, and `ggseqlogo` to draw differential genetic landscapes, project dynamic ROI highlights, and render contextual downstream sequence logos.

## Installation & Dependency Management

The entire environment (including Python libraries, R base, and CRAN/Bioconductor packages) is fully containerized and managed via Conda.

### Prerequisites
Ensure you have [Miniconda](https://docs.conda.io/en/latest/miniconda.html) or Anaconda installed.

### Setup Environment
1. Clone or download this repository to your local machine.
2. Open your terminal, navigate to the repository directory, and run:

`conda env create -f environment.yml`

3. Activate the newly created workspace:

`conda activate bacgwas_env`

## Pipeline Usage & Command Line Interface (CLI)
Once activated, execution is fully streamlined through a single command-line interface.

```bash
python bacgwas_visualizer.py \
  --vcf ruta/a/tus/unitigs.vcf \
  --pheno ruta/al/phenotype.txt \
  --gwas ruta/al/pyseer_output.tsv \
  --type unitig \
  --case-name "Case" \
  --control-name "Control" \
  --outdir Resultados_BabA \
  --pval 1e-5
```

## Parameter Description

Flag,Alternative,Required,Description
-v,--vcf,Yes,Input variant file (.vcf or .vcf.gz). Contains binary presence/absence matrices for every strain.
-p,--pheno,Yes,Tab/Space-separated phenotype metadata. Format: ID_Cepa  [0/1].
-g,--gwas,Yes,Complete raw output matrix generated by Pyseer (.tsv).
-r,--ref,No,Reference genome/gene in FASTA format (.fasta). Mandatory for Spatial Mapping and Clustering.
-t,--type,No,"Variant category. Choices: [snp, unitig, kmer]. (Affects plot titles and axis terminology)."
-c,--case-name,No,"User-defined label for cases (Phenotype 1). e.g., ""GC"" or ""Resistant""."
-n,--control-name,No,"User-defined label for controls (Phenotype 0). e.g., ""NAG"" or ""Sensitive""."
-o,--outdir,No,"Destination folder name for generated logs, datasets, and high-res vector graphics."
--pval,,No,Statistical significance alpha threshold line (Default: 1e-5).


## Expected Input Formats
1. Phenotype Metadata File (`-p / --pheno`)
A clean, header-less or standardized text file map linking your strain naming topology directly with case/control statuses:

```
HpGP-PER-104-Duplicated-1-KVJ61-01550    1
HpGP-NGA-010-KVJ62-04305                  0
HpGP-USA-420-KVM04-04160                  1
```

2. Pyseer Output TSV (`-g / --gwas`)
The unmodified full-length tabular summary outputted by Pyseer containing calculated statistical limits (lrt-pvalue, beta, af):

```
variant    variant_md5    lrt-pvalue    beta    af
AAATCCAGCTTTTTCAACTCGGCTTCTGACGT    8f9c...    2.4e-08    -0.245    0.42
ATCGTGGGCTACGTGACGCAATGCGGCGGTA    3b1a...    5.1e-03    0.012     0.11
```

```

```
